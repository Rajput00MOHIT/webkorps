# Services Assets Directory Structure

Organized asset storage for all Webkorps service offerings and detail pages.

```
src/assets/services/
├── IOT/                             # IoT Application Development assets
│   ├── iot-hero.png
│   └── service-iot.png

├── web-development/                 # Alias for Web Development
├── custom-software/                 # Custom Software Development assets
│   ├── custom-software.png
│   ├── service-custom.png
│   ├── product-discovery-strategy.png
│   ├── enterprise-software-platforms.png
│   ├── cloud-devops-solutions.png
│   └── integrations-apis-legacy.png

│   └── mobile-application-development.png
```

### Usage Guidelines:
1. When adding new images or 3D visual assets for a service, place them directly into the corresponding subfolder above.
2. Use descriptive, lowercase kebab-case naming for all new files (e.g., `telemetry-dashboard.png`, `device-gateway.png`).
3. Keep the shared `business-outcomes/` and `common/` folders for assets used across multiple services.
